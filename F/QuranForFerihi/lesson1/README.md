# Learn Arabic → Quran Reading

Upload the files to a GitHub repository and enable GitHub Pages from `main` / root.

For iPhone offline pronunciation: Settings → Accessibility → Spoken Content → Voices → Arabic → download an Arabic voice. Then open the site in Safari and use Share → Add to Home Screen.

The service worker caches the app after the first online visit. Speech uses the device's installed Arabic speech voice; it is not a tajweed recitation engine.
