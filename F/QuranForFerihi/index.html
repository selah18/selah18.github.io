Set up Learn Arabic for offline use

Do these steps once while you are online.

📲 Add to Home Screen on iPhone

  1. Open this GitHub Pages link in Safari.
  2. Tap the Share button.
  3. Scroll down and tap Add to Home Screen.
  4. Tap Add.
  5. Open Learn Arabic from your Home Screen.

🗣️ Install the Arabic voice

Settings → Accessibility → Spoken Content → Voices → Arabic

Download an Arabic voice. Then return to this app and press Play Arabic alphabet — OFFLINE.

The app uses the device's Arabic speech engine. The website itself does not need an internet connection after it has been cached.

✈️ Test offline mode

  1. While online, open the app once and use Learn, Flashcards and Quiz.
  2. Add it to the Home Screen.
  3. Turn on Airplane Mode.
  4. Open the Home Screen app again.
