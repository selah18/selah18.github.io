Publisher dashboard

Publish monthly editions from your public Google Drive folder without copying the PDF into GitHub. The dashboard detects the month/year/issue from the filename, renders the real first PDF page as the magazine cover, uploads that cover to GitHub, and stores the Drive PDF link in editions.json.

1. GitHub connection

Repository permission required: Contents → Read and write. The token stays in this browser and is never written to the site.

2. Google Drive source

Files must be shared as Anyone with the link → Viewer.

Use a browser-safe API key restricted to the Google Drive API and your GitHub Pages domain. It is only used to read public Drive files.
